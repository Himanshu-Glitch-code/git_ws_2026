# Git Basics

## What Is a Repository?

A repository is a project whose files and history are tracked by Git.

## What Is a Commit?

A commit records a snapshot of staged changes.

## What Is a Branch?

A branch lets you work on changes separately from another branch.

## What Is a Pull Request?

A pull request proposes changes for review before they are merged into another branch.

## What Is a Merge Conflict?

A merge conflict occurs when Git cannot automatically combine certain changes.

## A Typical Workflow

1. Find an issue.
2. Create a branch.
3. Edit a file.
4. Stage your changes.
5. Commit your changes.
6. Push your branch.
7. Open a pull request.
8. Get the changes reviewed.
