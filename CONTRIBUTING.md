# Contributing Guidelines

Welcome! You don't need to be an expert to contribute here.

## How to Contribute

1. Find an issue that you would like to work on.
2. Create a branch for your changes.
3. Make the required changes.
4. Review your changes using `git diff`.
5. Stage and commit your changes.
6. Push your branch to GitHub.
7. Open a pull request describing your changes.

## Branch Naming

Use descriptive branch names.

Examples:

- `docs/fix-readme`
- `docs/update-setup`
- `docs/fix-git-guide`

## Commit Messages

Write short messages that explain what you changed.

Examples:

- `Fix README instructions`
- `Add Git setup steps`
- `Correct clone command`

## Pull Requests

Your pull request should explain:

- What you changed
- Why you changed it
- Which issue it addresses, if applicable

Keep changes small and focused.

If you need help, ask a workshop mentor!
