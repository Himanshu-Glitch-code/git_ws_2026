# Useful Git Commands

| Command | Purpose |
|---|---|
| `git status` | Check the state of your repository |
| `git log --oneline` | View recent commits |
| `git diff` | View unstaged changes |
| `git add <file>` | Stage a file |
| `git diff --staged` | View staged changes |
| `git commit -m "message"` | Create a commit |
| `git branch` | List local branches |
| `git switch -c <name>` | Create and switch to a branch |
| `git push` | Send commits to a remote |
| `git pull` | Fetch and integrate remote changes |
| `git clone <url>` | Create a local copy of a repository |

## Remember

- `git add` stages changes; it does not commit them.
- `git commit` records staged changes locally.
- `git push` sends your commits to a remote repository.
- `git pull` brings remote changes into your current branch.
